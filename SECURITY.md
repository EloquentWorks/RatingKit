# Security Policy 🔐

## Supported Versions

Security updates are provided for the latest stable release.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub's security advisory feature for the repository.

Include:

- A description of the issue
- Reproduction steps
- Affected versions
- Potential impact
- A proposed fix, when available

Do not publish exploit details before a fix is available.

## Rating Integrity

Reports involving duplicate match processing, unsafe rollback, race conditions, unauthorized manual adjustment, or leaderboard manipulation are treated as security-sensitive when they could affect production competition data.
